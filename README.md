# Implementing a RAG Model on the ORCD Documentation

## Setting Up

Connect to Engaging OnDemand: [orcd-ood.mit.edu](orcd-ood.mit.edu)

Start a Jupyter notebook by clicking **Interactive Apps** > **Jupyter Notebook**

Request 4 CPUs, 16GB of memory, and a GPU. You can use the default Jupyter kernel. Click **Launch**.

Once your session has started, click **Connect to Jupyter**.

Open up a new terminal window on the Jupyter interface (open a new tab and click **Terminal**). Then, clone this GitHub repository.

The GitHub repository should appear as a folder in the left-hand pane. Open the `orcd_rag_ollama.ipynb` file and proceed with the instructions outlined in the notebook.
